# AimTrack Competition Clock (Windows)

World Archery competition clock for halls, ranges and TVs: walk-up, shooting and 30-second warning phases, AB / CD rotation, practice ends, alternate shooting for finals, emergency stop, 10 signal sounds and a full-screen colour cue that can be read from the shooting line. Works offline. Runs on Windows 7 SP1, 8, 10 and 11 (.NET Framework 4.8).

**Download:** https://www.aimtrack.io/download

The same clock runs in the browser at https://www.aimtrack.io/clock and can be shared with screens and phones through a room code.

This repository only hosts the installers. SHA-256 checksums are listed in each release.
